# Sharades title screen
The app now opens on the generated Sharades Party Challenge title-screen artwork. Tapping/clicking anywhere on the splash opens the existing bilingual in-app tutorial.

Artwork source: OpenArt hosted image URL used by `js/title-screen.js`. The artwork is currently loaded from the hosted URL, so it is not yet bundled for first-launch offline use; replace it with a committed local image asset when the binary asset upload is available.
